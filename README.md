# Repositório Geral de Jogos Godot

Bonjour! Aqui tem scripts e projetos que desenvolvi utilizando a engine [Godot](https://godotengine.org/), tanto em **GDScript** quanto em **C#**.

## 🌟 Objetivo
Este repositório tem como propósito manter arquivado scripts e projetos que fiz, podem servir como:
- Exemplos educativos para outros desenvolvedores.
- Inspiração para novos projetos.
- Recursos reaproveitáveis em outras criações na Godot.

## 📂 Estrutura do Repositório
O repositório está organizado da seguinte forma:

```
GS_gdscript/
├── gdscript/       # Scripts e projetos desenvolvidos em GDScript
├── csharp/         # Scripts e projetos desenvolvidos em C#
└── README.md       # Este arquivo
```

### Diretórios principais
- **gdscript/**: Scripts e projetos feitos em GDScript.
- **csharp/**: Scripts e projetos feitos em C# para Godot.

## 🚀 Como Usar
1. Clone o repositório:
   ```bash
   git clone
   ```
2. Importe os projetos na Godot para explorá-los ou utilize os scripts em seus próprios projetos.
