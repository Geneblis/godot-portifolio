\# 🎮 Godot 3D Projects



Aqui estão meus \*\*protótipos e jogos 3D\*\* feitos na \*\*Godot Engine\*\*.

Foram poucos projetos, mas cada um serviu pra entender melhor o funcionamento do 3D na engine — especialmente câmera, colisão e pathfinding.



---



\## 🔹 Destaques



\### 🧠 FpsZoomGame



Meu projeto 3D mais completo até agora — um \*\*FPS\*\* com:



\* Sistema de armas (disparo, reload e recoil)

\* \*\*Headbob\*\* funcional

\* Inimigos com \*\*pathfinding\*\* e animações simples

\* Estrutura modular para expansão



📌 \*\*Status:\*\* Jogável / Protótipo completo



---



\### 🎥 TopDownShooterGame



Um shooter \*\*top-down 3D\*\* com:



\* \*\*Câmera dinâmica\*\* e sistema de rotação próprio

\* Movimentação fluida

\* Base sólida para jogos de ação tática



📌 \*\*Status:\*\* Protótipo estável



---



\## ⚙️ Como abrir



1\. Instale \*\*Godot 4.5\*\*

2\. Clone o repositório

3\. Abra o projeto desejado (`Project > Open`)

4\. Execute a cena principal (`Main.tscn`)



---



\## 💡 Observações



\* Todos os projetos usam \*\*assets gratuitos ou autorais\*\*

\* Hardware e desempenho variam conforme o projeto

\* Alguns sistemas (como IA e câmera) foram feitos \*\*do zero\*\*
