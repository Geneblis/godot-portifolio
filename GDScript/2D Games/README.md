\# 🎮 Godot 2D Projects Collection



Este repositório reúne vários projetos e protótipos que desenvolvi ao longo do meu tempo estudando e criando jogos na engine \*\*Godot\*\*.

Cada um deles explora diferentes conceitos de jogabilidade, IA, e sistemas de combate.



\### 🧩 Destaques



\* \*\*2D RTS Prototype\*\*

&nbsp; Um protótipo de estratégia em tempo real com \*\*pathfinding A\*\*\* totalmente funcional, incluindo \*\*formação de grid\*\* dinâmica quando várias unidades se sobrepõem.



\* \*\*Meu Segundo Jogo\*\*

&nbsp; Literalmente o meu segundo jogo criado na engine — simples, mas um marco pessoal no aprendizado de Godot.



\* \*\*Sidescroller\*\*

&nbsp; Meu primeiro protótipo \*\*completamente jogável\*\* do início ao fim.

&nbsp; Embora curto, representa o primeiro passo real em direção a um jogo completo.



\* \*\*2D Top-Down Shooter\*\*

&nbsp; Sistema top-down funcional com inimigos utilizando \*\*A\*\*\* para navegação.

&nbsp; Ainda em estágio inicial de gameplay, mas com toda a base técnica pronta.



\* \*\*Turn-Based Combat Prototype\*\*

&nbsp; O projeto \*\*mais complexo\*\* que já desenvolvi até agora, inspirado em um minigame de \*\*Metal Gear Solid: Peace Walker\*\*.

&nbsp; Possui um sistema completo de turnos, unidades e combate tático em grid.
